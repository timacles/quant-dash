Main Page Navigation — 3 Design Suggestions

How to organise the main dashboard page, its 5 data sections, and the config / utility pages. Each suggestion includes a rendered diagram and a live mockup.

A · Sticky Sidebar B · Accordion Groups C · Dropdown Switcher Comparison Recommendation
A

Sticky Sidebar with Section Tabs

sidebar · two-column

Replace the single-column layout with two columns: a narrow sidebar that sticks on scroll, and the main content area on the right. Every section + config gets a row in the sidebar.

Pros

  • Always-visible orientation — all sections at a glance
  • No content reflow from the existing card grid
  • Natural place for config link alongside data sections

Cons

  • Requires layout refactor (HTML + CSS)
  • Sidebar gets long with 10+ sections
B

Accordion Section Groups with Sticky Strip

groups · sticky strip · single-column

Keep the single-column layout but group related sections under conceptual headers (Momentum, Reversion, Compression). A sticky pill strip below the hero lets users jump between groups. Config gets its own pill in the strip.

C

Dropdown Section Switcher with Inline Config

dropdown · single-section · slide-out config

Show one section at a time, selected via a dropdown selector. A gear icon opens an inline config panel (slide-out or modal) so the user can reorder columns without leaving the page. The config page becomes unnecessary.

Pros

  • Maximum horizontal space — no sidebar or multi-card layout
  • Focused view: user sees exactly one section at a time
  • Inline config eliminates the separate /config page
  • Fast — only one section's data fetched at a time

Cons

  • No at-a-glance overview — must switch to compare
  • Requires a JS dropdown + config panel (medium effort)
  • May frustrate users who want Longs & Shorts side by side

Recommendation: B · Accordion Groups

Suggestion B is the most practical starting point given the current codebase. It works within the existing single-column HTML + CSS template, requiring no layout refactor. The sticky group strip adds minimal JS (scroll-into-view on click). Grouping the 5 existing sections into 3 groups (Momentum, Reversion, Compression) provides immediate navigational value. Config can be added as a pill in the strip, keeping the separate /config page as a fallback. As new sections are added (e.g. sector momentum, commodity trends), the group model scales naturally.
